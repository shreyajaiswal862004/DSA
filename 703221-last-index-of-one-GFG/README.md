# [Last index of One](https://www.geeksforgeeks.org/problems/last-index-of-15847/1?utm=codolio)
## Easy
Given a string s consisting only of '0' and '1', find the last index at which '1' occurs. If '1' is not present in the string, return -1.
Examples:
Input: s = "01001"
Output: 4
Explanation: Last index of&nbsp; 1 in given string is 4.

Input: s = "0"
Output: -1
Explanation: Since, 1 is not present, so output is -1.
